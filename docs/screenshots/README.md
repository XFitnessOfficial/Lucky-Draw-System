# Screenshots

Drop your images here, then reference them from the main README with relative
paths — `![Alt text](docs/screenshots/filename.png)`.

Committing them to the repo (rather than pasting them into the README editor,
which uploads to GitHub's user-content CDN) means they are versioned with the
code and survive a fork or a clone.

Suggested set, matching the placeholders in the README:

| Filename | What to capture |
|---|---|
| `customer-page.png` | The public page on a phone — hero, ticket count, the four ways to earn |
| `admin-console.png` | The staff console Overview tab — stat cards, activity feed, ledger strip |
| `draw-arena.png` | The live draw arena mid-reveal, with the foil ticket and a name lifted in |
| `kiosk.png` | Kiosk mode on a tablet at the front desk |

Keep each under about 500 KB. PNG for UI, JPG for anything photographic.
Two-times device pixel ratio is plenty; a 4K screenshot just makes the clone
slower for everyone.

**Before you commit any screenshot, check it for real customer data** — names,
phone numbers, ID numbers, social handles. The admin console shows all of them.
Use test records, or blur the columns.
